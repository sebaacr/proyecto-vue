# Backend NestJS - Emprendedores de Ñuble (Actividad 10)

Backend migrado desde Express.js a **NestJS** con arquitectura modular, persistencia de datos mediante **TypeORM + SQLite**, validaciones de entrada con `class-validator` y documentación interactiva con **Swagger**.

## 🚀 Tecnologías

- **Framework**: NestJS
- **ORM**: TypeORM
- **Base de Datos**: SQLite (`better-sqlite3`)
- **Validación**: `class-validator` y `class-transformer`
- **Documentación**: OpenAPI / Swagger
